# Spaceific beta

Spaceific shows what is using your Mac's disk, and helps you clear developer caches, build folders and local AI models without removing the wrong thing.

This repository holds only the closed beta's downloads, for invited testers. The source is not here.

Download the .dmg from Releases, check its SHA-256, and read "Read Me First.txt" inside it before you open Spaceific. The beta is not notarised by Apple yet, so macOS stops it the first time; the Read Me says what to do.

Feedback: Help → Send Feedback… in Spaceific, or hello@spaceific.app.
